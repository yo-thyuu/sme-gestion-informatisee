# Start Here — Système Modulaire de Gestion Informatisée

**Workspace package:** 1.0 (consolidated working baseline)  
**Project folder:** `Project_02_SME_Management_System`  
**Application status:** minimal runnable Python starter; the business workflow is not implemented yet.

## What this package is

This is the single working project folder for the ILEIC Gestion Informatisée project. It consolidates the accepted design, project notes and learning status into one authoritative file per topic. Older overlapping document versions have been merged or removed from the active package.

It includes a minimal `main.py` so you can open and run the project in PyCharm. It does **not** include PyCharm itself, Python itself, or a prebuilt virtual environment. Those stay installed/configured on your computer. No third-party Python packages are required for the current milestone.

## Read in this order

1. `docs/NOTEBOOK_SUMMARY.md` — purpose, long-term vision, scope, learning method and phases.
2. `docs/PROJECT_STATUS.md` — what is complete and the precise next learning step.
3. `docs/DESIGN_DECISIONS.md` — accepted choices; do not re-open them without a real reason.
4. `docs/DATA_MODEL.md` — the conceptual data model.
5. `docs/REQUIREMENTS.md`, `docs/BUSINESS_PROCESS.md` and `docs/BUSINESS_RULES.md` — what the first workflow must do.
6. `docs/PYCHARM_SETUP.md` — safe setup and run instructions.

## Run the starter

1. Open this project folder in PyCharm (the folder that contains `main.py`).
2. Select your installed Python interpreter. Use a project-local `.venv` if one is not already configured.
3. Open `main.py` and run it.
4. Confirm the console shows the project name and the first workflow milestone.

Do not install packages yet. We will add code gradually, understand each concept before using it, and test business behavior as it is built.

## Working-copy rule

After this consolidated package is installed, keep editing the same project folder. Do not replace it with a new ZIP for every lesson. Create a new package snapshot only at a meaningful milestone or before a risky change. Keep a backup of your previous folder until you verify this one opens and runs.
