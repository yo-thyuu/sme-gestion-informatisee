# SME — Gestion informatisée

A Python learning project focused on managing purchasing, goods receipts, stock, and exceptions for a fictional small business.

**Status:** Early development — learning and implementation in progress.

## Project objectives

- Understand and model a real business workflow.
- Apply Python concepts through practical development.
- Handle purchase orders and goods receipts correctly.
- Gradually develop reliable stock and exception-management features.

## Currently implemented

- Basic purchase-order data using Python dictionaries and lists.
- Displaying purchase-order information.
- Classifying received quantities into accepted and damaged goods.

## Planned features

- Purchase-order and goods-receipt workflows.
- Partial deliveries and damaged-goods handling.
- Stock movements and duplicate-posting prevention.
- Exception tracking and traceable corrections.
- Data persistence and more comprehensive testing.

These are project goals, not claims that the features are already implemented.

## Technology

- Python
- PyCharm
- Git / GitHub

## Run

    python main.py

## Learning approach

Each development step follows a small cycle: understand the business rule, learn the relevant Python concept, predict the result, run the code, test it, debug it, and explain the solution.

## Project limitations

This is an educational project in development. Its features, reliability, and completeness will be documented as implementation and testing progress.
